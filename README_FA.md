یک مخزن پروژه‌محور و گام‌به‌گام برای پیاده‌سازی مهندسی سیستم‌های مبتنی بر مدل‌های زبانی بزرگ (LLM) با استفاده از **Python**، فریم‌ورک **FastAPI**، پایگاه‌داده **SQLite** و فناوری‌های نوین وب.

---

## نمای کلی پروژه

توسعه نرم‌افزارهای کاربردی مبتنی بر هوش مصنوعی نیازمند رعایت الگوهای حرفه‌ای مانند مدیریت حافظه، کنترل مصرف توکن‌ها و هزینه‌ها، امنیت اندپوینت‌ها و تفکیک نشست‌های کاربران است. این مجموعه به شکل گام‌به‌گام از ساخت یک گیت‌وی ایمن API شروع شده، با پیاده‌سازی مدیریت حافظه گفتگویی ادامه یافته و به یک وب‌اپلیکیشن چت‌بات فول‌استک با قابلیت انتقال سشن‌های مهمان به حساب کاربری ختم می‌شود.

نکات برجسته:
- **عدم وابستگی به سرویس‌دهنده (Zero Vendor Lock-in):** مدیریت محلی حافظه به جای ترد‌های پولی و پرهزینه سمت ارائه‌دهنده.
- **معماری دفاعی وب‌سرویس:** اعتبارسنجی دقیق متدهای مجاز HTTP (مسدودسازی متدهای غیرمجاز با خطای ۴۰۵) و مدیریت خطاها.
- **معماری فول‌استک:** ارتباط تمیز میان اندپوینت‌های FastAPI، ذخیره‌سازی ماندگار SQLite و رابط کاربری تعاملی.
- **انتقال هوشمند سشن مهمان:** انتقال خودکار تاریخچه ۳ سشن رایگان مهمان به حساب کاربری پس از ورود یا ثبت‌نام.

## جدول تسک‌ها و مراحل پیاده‌سازی

| تسک | عنوان | تمرکز اصلی | تکنولوژی‌ها |
| :--- | :--- | :--- | :--- |
| [`task-01`](task-01/) | **گیت‌وی اختصاصی API هوش مصنوعی** | اندپوینت اختصاصی `/chat` با متد POST، اتصال به OpenRouter، کنترل هدرها و اعتبارسنجی | FastAPI, OpenRouter, Uvicorn |
| [`task-02`](task-02/) | **مدیریت حافظه مکالمه (Conversational Memory)** | مدیریت کانتکست با پنجره متحرک (Sliding Window) شامل ۱۰ پیام آخر (۵ پیام کاربر + ۵ پاسخ مدل) | FastAPI, Pydantic, حافظه محلی |
| [`task-03`](task-03/) | **چت‌بات وب فول‌استک با مدیریت نشست‌ها** | وب‌اپلیکیشن چت، سهمیه مهمان، احراز هویت، مهاجرت سشن، سایدبار مدیریت گفتگوها | FastAPI, SQLite, جاوااسکریپت, Tailwind CSS |

---

### ۱. تسک ۱ (`task-01`): درگاه اختصاصی هوش مصنوعی
* ایجاد اندپوینت `/chat` که تنها متد `POST` را می‌پذیرد و متدهای دیگر را با خطای `405 Method Not Allowed` رد می‌کند.
* ارسال درخواست به OpenRouter و بازگرداندن پاسخ هوش مصنوعی همراه با مدیریت خطاهای شبکه و قطع ارتباط.

### ۲. تسک ۲ (`task-02`): حافظه محاوره‌ای با پنجره متحرک
* برطرف کردن ماهیت بدون وضعیت (Stateless) مدل‌های زبانی از طریق مدیریت سمت برنامه (Application-Managed Memory).
* استفاده از استراتژی **پنجره متحرک (Sliding Window)** برای حفظ ۱۰ پیام اخیر جهت جلوگیری از انفجار سایز کانتکست و بهینه‌سازی مصرف توکن‌ها.

### ۳. تسک ۳ (`task-03`): چت‌بات وب فول‌استک با مدیریت کاربران
* پیاده‌سازی رابط کاربری کامل با منوی کناری (سایدبار) برای پین کردن، تغییر نام و حذف گفتگوها.
* **سیستم سهمیه کاربر مهمان**: امکان ایجاد ۳ سشن چت برای کاربران مهمان و انتقال یکپارچه این داده‌ها به حساب کاربری پس از ورود.
* رندر کامل متون Markdown همراه با هایلایت کدها و اعلان‌های مدرن Toast.

## نصب و راه‌اندازی

### پیش‌نیازها

- پایتون نسخه ۳.۱۰ یا بالاتر
- کلید API از OpenRouter (یا ارائه‌دهنده‌های سازگار با ساختار OpenAI)

### مراحل نصب

۱. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/docRoch/ai-implementation.git
   cd ai-implementation
   ```

۲. **ایجاد و فعال‌سازی محیط مجازی پایتون:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

۳. **نصب پکیج‌های مورد نیاز:**
   ```bash
   pip install -r requirements.txt
   ```

۴. **تنظیم متغیرهای محیطی:**
   ```bash
   cp .env.example .env
   # کلید OPENROUTER_API_KEY را داخل فایل .env قرار دهید
   ```

### اجرای پروژه‌ها

- **اجرای تسک ۱:**
  ```bash
  cd task-01
  python main.py
  ```

- **اجرای تسک ۲:**
  ```bash
  cd task-02
  python app.py
  ```

- **اجرای تسک ۳:**
  ```bash
  cd task-03
  python app.py
  # در مرورگر آدرس http://localhost:8000 را باز کنید
  ```
