## ساخت وب‌سرویس سفارشی هوش مصنوعی با متد اختصاصی POST

هدف این تسک ایجاد یک اندپوینت تحت وب اختصاصی جهت ارتباط ایمن با مدل‌های زبانی از طریق OpenRouter به جای استفاده از اسکریپت‌های خام کلاینتی بود.

با استفاده از فریم‌ورک **FastAPI** و وب‌سرور **Uvicorn**، اندپوینت `/chat` پیاده‌سازی شد. این اندپوینت به صورت سخت‌گیرانه تنها درخواست‌های دارای متد `POST` را می‌پذیرد و متدهای دیگر نظیر `GET` را فوراً با خطای استاندارد `405 Method Not Allowed` رد می‌کند.

### مفاهیم و آموخته‌های کلیدی:
- **ساختار درخواست (Request Payload & Headers):** تعریف هدرهای احراز هویت با توکن اختصاصی و ساختاربندی بدنه پیام ارسالی شامل فیلدهای `model`، `max_tokens` و آرایه مکالمات (`messages`).
- **مدیریت دفاعی خطاها:** کپسوله‌سازی ریکوئست به OpenRouter در بلوک `try...except` و بررسی کدهای وضعیت پاسخ (Status Code 200) و هندل خطاهای شبکه.
- **استخراج پاسخ:** پارس کردن خروجی JSON مدل و استخراج مستقیم متن تولیدشده از فیلد `choices[0].message.content`.
